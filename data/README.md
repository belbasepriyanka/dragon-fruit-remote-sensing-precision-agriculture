# Data

## Public demonstration dataset

The full demonstration dataset is generated by `src/data_generation.py` with a fixed random seed. It mirrors the structure of a multi-factor specialty-crop experiment but does **not** contain unpublished doctoral research measurements.

The generated demo contains 72 synthetic plants, 3 crop groups, 4 amendment rates, 2 production environments, 3 replicates, and 4 observation dates (120, 365, 649, and 960 days after planting).

### Why synthetic data?

The repository demonstrates analytics, coding, validation, and decision-support workflows without publishing confidential or unreleased research data. Replace the generated table with measured data only after matching the input schema and documenting provenance.

### Recreate the data

```bash
python src/data_generation.py
```

Or regenerate the full analysis:

```bash
python scripts/run_demo.py
```

### Key fields

`plant_id`, `environment`, `species`, `treatment_t_acre`, `replicate`, `dap`, weather, growth, flowering/fruit counts, soil nutrients, tissue nutrients, NDVI, NDRE, GNDVI, red-edge slope, NIR/SWIR summaries, and `stress_flag`.
